# cachy-omarchy-overlay

기존 CachyOS + Hyprland 위에 Quickshell 기반 Quattro 런처를 올리는 **데스크톱 오버레이**입니다. Omarchy 전체를 설치하는 프로그램이 아닙니다.

기존 설정, 바, 알림, 잠금 화면, 셸은 건드리지 않습니다.

## 키바인딩

```text
SUPER + SPACE  → Quattro 스타일 런처 / 메뉴
SUPER + K      → 검색 가능한 키바인딩 치트시트
```
